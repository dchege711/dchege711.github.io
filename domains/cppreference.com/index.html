Design a locker system like Amazon Locker where delivery drivers can deposit packages and customers can pick them up using a code.

Clarifying Questions

  • Establish scope: Are we modeling just the piece from when the driver arrives at the locker until the customer? How does the customer get the code?
  • Questions on core flows: Are there different sized compartments? Can a small package go into a large compartment if the small ones are full? Are access tokens unique per package?
  • Edge cases: What if someone enters the wrong code multiple times? What happens to a package if it’s never picked up? What if all compartments of a given size are full when a driver tries to deposit?
